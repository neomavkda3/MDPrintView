# mdview

Native macOS markdown editor + viewer with print-quality typography.

Target: macOS 26+. Distribution: Mac App Store.

See `docs/plans/2026-06-01-mdview-design.md` for the design.

## Build system

The Xcode project is generated by [XcodeGen](https://github.com/yonaskolb/XcodeGen) from `project.yml`. To regenerate after editing `project.yml`:

```sh
xcodegen generate
```

Both `project.yml` and the generated `mdview.xcodeproj` are tracked in git. **`project.yml` is the source of truth — do not hand-edit `mdview.xcodeproj/project.pbxproj`; changes will be lost on the next regenerate.**

Install XcodeGen via Homebrew if needed:

```sh
brew install xcodegen
```
