MDPrintView

A native macOS markdown editor with print-quality typography.

⬇ Download for Mac

macOS 26+ · Apple Silicon and Intel · Free and open source (GitHub)

What it does

  • Three layout modes

    Editor, Split, or Preview-only. Switch with one keystroke.

  • Four reading themes

    Original, Focus, Sepia, and Print. Match the mood you write in.

  • Print-quality output

    Page breaks respect headings, code blocks, and tables. Export to PDF or send to any printer.

  • Diagrams and math

    Mermaid diagrams and LaTeX math (KaTeX) render in the preview pane and the print output.

  • Live external-edit reload

    Edit the file in another tool (vim, Claude Code, VS Code) and MDPrintView updates in place.

  • 11 fonts plus your own

    Curated font picks for editing, with the standard macOS Fonts panel for anything else installed on your system.

  • System / Light / Dark

    Override macOS appearance per-app.

  • Privacy-first

    Zero network calls. Nothing leaves your Mac. Privacy Manifest declared.

How to install

  1. Click Download for Mac above. On the page that opens, download the file ending in .dmg (under Assets).
  2. Double-click the downloaded file. A window opens showing the MDPrintView icon.
  3. Drag the MDPrintView icon into the Applications folder shortcut in the same window.
  4. Open MDPrintView from Launchpad or your Applications folder.

macOS may take a moment to verify the app on first launch. This is normal and won't happen again. There's no "unidentified developer" warning: MDPrintView is signed and notarized by Apple. Updates download automatically; you can also check anytime from MDPrintView → Check for Updates….

Common questions

Is it really free?

Yes. MDPrintView is open source under the GPL-3.0 license. No subscriptions, no in-app purchases, no tracking.

Does it work offline?

Yes. MDPrintView has no network access at all. Everything runs locally on your Mac.

What if I see a security warning?

You shouldn't. The app is signed and notarized by Apple. If you do, right-click MDPrintView in Applications and choose Open. You'll only need to do this once.

Where do I report a bug or request a feature?

On the GitHub Issues page. Bug-report and feature-request templates are provided.

How do sponsorship funds reach new grads?

Sponsorship dollars flow through ANCOP Canada, which works directly with new graduates entering the sports tech industry, providing laptops, software subscriptions, training, and AI/cloud credits. The first ~$8/month covers MDPrintView's Apple Developer Program fee (so the app stays signed and notarized for everyone); everything beyond that goes to the new-grad tooling fund.
