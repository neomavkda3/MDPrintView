The markdown editor built for print-quality output.

Native macOS markdown editor. Three layout modes, four reading themes, Mermaid diagrams, LaTeX math, and a print pipeline that keeps headings, code blocks, and tables together across page breaks.

Download for Mac View on GitHub

Features

  • Three layout modes Editor, Split, or Preview-only. One keystroke to switch.
  • Four reading themes Original, Focus, Sepia, Print.
  • Print-quality output Page breaks respect headings, code blocks, and tables.
  • PDF export One shortcut, identical to the print preview.
  • Diagrams and math Mermaid in fenced blocks, KaTeX for inline and display math.
  • Live external-edit reload Edit in vim or Claude Code; MDPrintView updates in place.
  • 11 fonts plus your own Curated picks for editing, plus the standard macOS Fonts panel.
  • System / Light / Dark Per-app appearance override.
  • Welcome screen Recent + pinned documents with search and previews.
  • Document tabs Multiple files cluster as tabs in a single window.
  • Privacy-first Zero network calls. Sandbox-ready. Privacy Manifest declared.

How to install

  1. Click Download for Mac above. On the page that opens, download the file ending in .dmg under Assets.
  2. Double-click the downloaded file. A window opens with the MDPrintView icon.
  3. Drag the MDPrintView icon into the Applications folder shortcut.
  4. Open MDPrintView from Launchpad or your Applications folder.

macOS may take a moment to verify the app on first launch. This is normal and won't happen again. There's no "unidentified developer" warning. MDPrintView is signed and notarized by Apple. Updates download automatically.

FAQ

Is it really free?

Yes. MDPrintView is open source under GPL-3.0. No subscriptions, no in-app purchases, no tracking.

Does it work offline?

Yes. MDPrintView has no network access at all. Everything runs locally on your Mac.

What if I see a security warning?

You shouldn't. The app is signed and notarized by Apple. If you do, right-click MDPrintView in Applications and choose Open. You only need to do this once.

Where do I report a bug or request a feature?

On the GitHub Issues page. Bug-report and feature-request templates are provided.

How do sponsorship funds reach new grads?

Sponsorship dollars flow through ANCOP Canada, which works directly with new graduates entering the sports tech industry, providing laptops, software subscriptions, training, and AI/cloud credits. The first ~$8/month covers MDPrintView's Apple Developer Program fee (so the app stays signed and notarized for everyone). Everything beyond that goes to the new-grad tooling fund.
